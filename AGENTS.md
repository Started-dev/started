# Started — product contract

This repo is the runtime. Studio is a viewer.

1. A Start is a versioned kit with a harness. No harness, no listing.
2. The engine is local-first. Default model endpoint is local. Cloud keys are BYO and user-initiated.
3. The runner is isolation, not inference. Same receipt schema as the engine.
4. Receipts are the unit of truth. An agent does not get a pass without evidence.
5. Do not add hosted inference, multiplayer, or a 40-tool MCP surface.
6. Official kits: `web-vite-app`, `base-erc20`, `local-agent-worker`.
